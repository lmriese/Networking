# Cisco Packet Tracer Network Design

A networking project developed using Cisco Packet Tracer focused on network topology design, routing, switching, IP addressing, and device connectivity.

## Features
- Router and switch configuration
- Network topology simulation
- IP addressing and subnetting
- Device connectivity testing
- Basic routing and switching setup

## Technologies Used
- Cisco Packet Tracer
- Networking Fundamentals
- Routing and Switching
